# Contributing to FreeCuli Standards

This repository holds the official whitepapers, compliance blueprints, and methodology standards for FreeCuli.

## Proposing Changes to the Standard
Because this repository acts as the global reference for offline smart kitchen privacy (KVKK / GDPR), changes are strictly regulated.
1. To propose an update, please open an **Issue** with the prefix [PROPOSAL].
2. Do not submit direct Pull Requests for documentation changes without prior discussion.
3. All proposals are reviewed by the **Yemek AI Engineering** steering committee.
